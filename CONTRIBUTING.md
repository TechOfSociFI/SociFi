# Contributing to SociFi

We are excited that you are interested in contributing to **SociFi**! Whether you're a developer, designer, community manager, or just someone passionate about Web3, we welcome your participation.

## Ways to Contribute

1. **Report Issues**: If you find a bug, have a feature request, or encounter anything else that seems off, please open an issue on GitHub.
2. **Submit a Pull Request (PR)**: If you have a fix or a feature to add, please submit a PR! Ensure your PR follows these guidelines:
   - Provide a clear description of the change.
   - Ensure the change doesn't break any functionality.
   - Write tests for new features, if applicable.
3. **Join Discussions**: We encourage open dialogue in our GitHub discussions or social media channels.
4. **Develop Smart Contracts or Bots**: Submit your smart contracts, NFT templates, or blockchain bots to the marketplace.

## Setting Up Your Development Environment

Follow these steps to set up the SociFi codebase on your machine:

1. Clone the repository:
   bash
   git clone https://github.com/socifi-protocol/socifi.git
2. Install dependencies (use Node.js, Solidity tools like Hardhat or Foundry for smart contract development):
npm install
3. Run tests:
   npm test
